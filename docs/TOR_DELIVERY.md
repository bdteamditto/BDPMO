# TOR / ส่งมอบ Spreadsheet

หน้า **TOR / ส่งมอบ** เป็น workspace สำหรับทีมโครงการดูและแก้ไขข้อมูลส่งมอบในหน้าเดียว โดยแบ่งเป็น 2 โซน

## 1. Project / Contract Information

แสดง:
- สัญญา
- สัญญาเลขที่
- วันที่ลงนามในสัญญา
- วันเริ่มต้นโครงการตามสัญญา
- ส่งมอบงานให้แล้วเสร็จภายในวันที่
- เลขโครงการ
- มูลค่าสัญญา

OWNER เป็นผู้แก้ข้อมูลสัญญาหลัก ส่วน EDITOR/VIEWER ดูได้

## 2. Milestone Sheet

ตารางมีคอลัมน์:
1. งวดงานที่
2. งวดเงินที่
3. สัดส่วนเงิน (%)
4. งวดตามสัญญา
5. สิ่งส่งมอบ
6. ขอบเขตของงาน
7. ข้อในสัญญา
8. กำหนดส่งมอบ (ตามสัญญา)
9. วัน
10. กำหนดส่งมอบ (ตาม TOR)
11. กำหนดส่งมอบ (ตามแผน)
12. เดือน
13. วันที่ส่งมอบ
14. เลขที่/วันที่ จดหมาย
15. เลขที่/วันที่ หนังสือตอบกลับ (ลูกค้า)
16. วันที่เซ็นต์รับมอบ (ลูกค้า)
17. สถานะ

Read Mode ใช้ติดตามภาพรวม และ Edit Mode ให้ OWNER/EDITOR แก้ cell โดยตรง

## งวดเงิน

งวดงานและงวดเงินไม่จำเป็นต้อง 1:1 เช่น งวดงาน 2 อาจเป็นงวดเงิน 1 ที่ 20% ระบบคำนวณมูลค่าเงินจากสัดส่วนเทียบมูลค่าสัญญา และไม่อนุญาตให้สัดส่วนรวมเกิน 100%

## Audit

ทุกการแก้ cell บันทึก actor, เวลา, งวดงาน, field, ค่าเดิม, ค่าใหม่ และ reason (ถ้ามี) ใน event history ของโครงการ

## Permission

- OWNER: แก้ Project/Contract info และ Milestone Sheet
- EDITOR: แก้ Milestone Sheet
- VIEWER: Read Mode เท่านั้น
